ABOUT THIS QUESTION BANK

每一道题，都有来处。

本网站按“课程讲义”中的5份章节讲义和2份 Tutorial 编写，每份60题，共420题。题目是教学练习与变式，不冒称 UvA 官方题库或考试真题。每题答案下方列有具体出题依据。

  • 课程讲义：Introduction、Data Types、Control Structures、Functions、Files and Data Handling、Tutorial 1、Tutorial 2。
  • Al Sweigart · Python Programming Exercises, Gently Explained（42题）
  • UvA Python 工作坊与 ubvu / Software Carpentry 公开练习
  • spcourse / pandas-dp（31题）
  • Jake VanderPlas · Python Data Science Handbook

怎样练习

先选章节和知识点，再选择题型、难度。选择题选好后点击“检查答案”；编程题在编辑框内写代码，点击“运行代码”查看输出，点击“检查测试”核对题目要求。参考答案与解析随时可以展开，查看答案不会自动标记通过。

编程检查使用题目所列的测试样例，帮助发现常见错误；它不能证明所有可能输入都正确。代码在浏览器的独立 Python 环境中执行，题目文件是教学小样本，不会读取电脑里的原始讲义文件。编辑器与 Python 运行组件随网页一起加载，无需另行安装。

版本与素材

Monaco Editor 0.52.2（MIT）；Pyodide 0.27.7（MPL-2.0），内含 Python 3.12、NumPy 2.0.2、pandas 2.2.3。卡通配图由内置 imagegen 生成，用于本网站。中英文切换保持代码与学习记录。右上角有中英文字体两个下拉框：中文 17 种可爱字体、英文 9 种可爱字体，可分别切换标题、按钮与关键阅读区域文字；数字跟随英文字体。
