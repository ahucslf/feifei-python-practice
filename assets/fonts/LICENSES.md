# 可爱字体来源与许可

站内共有两个字体下拉框：**中文字体（17 款）** 与 **英文字体（9 款）**，两者相互独立：改中文字体不影响英文，改英文字体不影响中文，数字跟随英文字体。

全部字体均为自托管 `woff2` 子集，用于本非商业学习网站；字体原始著作权归各作者所有，均按 **SIL Open Font License 1.1**（OFL-1.1）授权，完整许可文本见同目录 `OFL-1.1.txt`。子集化版本仅通过 CSS 自定义字体族名引用，未使用保留字体名（Reserved Font Name）作为新的字体名称。

子集范围：中文界面用字、章节名、知识点标签、420 道题的标题与题干中的全部汉字/中文标点（约 845 个非 ASCII 字符）。中文字体子集**不含拉丁字母与数字**，因此英文和数字会自然回退到英文字体，实现中英独立切换。
