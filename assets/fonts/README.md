# 可爱字体（ZCOOL KuaiLe 子集）

- 字体：ZCOOL KuaiLe（站酷快乐体），通过 `pyftsubset` 按页面用字子集化，文件 `zcool-kuaile-ui.woff2`（约 75 KB）。
- 覆盖范围：首页大标题、侧栏品牌字、章节标题、小标题、弹窗标题、答案标题，以及所有按钮/下拉框文字（含中文 UI 文案、章节名、知识点标签、数字与拉丁字母）。题目正文、解析、代码仍使用默认字体与等宽字体。
- 用法：右上角「可爱字体」按钮切换标题与按钮字体，选择保存在浏览器 localStorage，默认开启。
- 来源：Google Fonts（https://fonts.google.com/specimen/ZCOOL+KuaiLe），原始字体 ZCOOLKuaiLe-Regular.ttf。
- 许可：SIL Open Font License 1.1，完整许可见 `OFL-ZCOOLKuaiLe.txt`。
- 未包含的符号（如 ★、☰、✦、→）会自动回退到系统字体显示。
