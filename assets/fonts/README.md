# 可爱字体（标题与按钮）

- 站内「可爱字体」下拉框提供 **17 款**中文字体（另加「默认字体」共 18 项），用于首页大标题、品牌字、侧栏标题、章节标题、小标题、弹窗标题、答案标题，以及按钮/下拉框文字。
- 每款字体都是按本站 UI 用字（约 500 个字：中文界面文案、章节名、知识点标签、数字与拉丁字母）用 `pyftsubset` 子集化后的 `woff2`，共约 1.6 MB；页面默认只加载当前选中字体，打开下拉框预览时才会加载其余字体。
- 用法：右上角「可爱字体」下拉框选择，选择保存在浏览器 localStorage；题目正文、选项、解析和代码仍使用默认字体与等宽字体。
- 所有字体均按 **SIL Open Font License 1.1** 授权，逐款来源与版权信息见 `LICENSES.md`，许可全文见 `OFL-1.1.txt`。
- 未包含的符号（如 ★、☰、✦、→）自动回退系统字体显示。
- 另有 `zcool-kuaile-title.woff2`：站酷快乐体按 420 道题的**题干标题**用字扩充的子集（788 字形，覆盖 552 个题干标题汉字中的 551 个，仅 π 回退），专用于题目大标题；它不随下拉框切换，保证 60 道题的标题不会出现字体混排。
