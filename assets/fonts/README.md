# 可爱字体（中英双字体系统）

- 右上角有两个并排的字体下拉框：**✦ 中文字体**（17 款 + 默认字体，默认昭源环方）和 **Aa 英文字体**（9 款 + 默认字体）。
- 两者相互独立：改中文字体只影响汉字/中文标点，改英文字体只影响英文与数字；数字（题号、计数、统计等）跟随英文字体。
- 应用范围：首页大标题、品牌字、侧栏标题、章节标题、小标题、弹窗标题、答案标题、按钮/下拉框，以及面包屑、难度标签、题目标题、题干、侧栏「我的学习足迹」/寄语、题号分页、老师便签正文。代码块、行内代码、代码编辑器保持等宽字体；选项与答案解析保持默认字体。
- 中文字体子集覆盖约 845 个中文用字（含 420 道题的标题/题干用字），不含拉丁字母；英文字体子集为 ASCII + 常用西文标点，不含汉字。靠这套互补覆盖实现中英独立回退。
- 全部字体为 SIL OFL 1.1 自托管子集，逐款来源/版权见 `LICENSES.md`，许可全文见 `OFL-1.1.txt`。
- 未包含的符号（★、☰、✦、→ 等）自动回退系统字体显示。
