# 可爱字体（标题、按钮与关键阅读区域）

- 站内「可爱字体」下拉框提供 **17 款**中文字体（另加「默认字体」共 18 项），用于首页大标题、品牌字、侧栏标题、章节标题、小标题、弹窗标题、答案标题，以及按钮/下拉框文字。
- 同时按页面截图要求，额外覆盖这些关键阅读区域：顶栏面包屑、难度标签、题目标题、题干文字、侧栏「我的学习足迹」与寄语、题号分页（第 x / 60 题）、老师便签正文。代码块、行内代码与代码编辑器始终使用等宽字体；选项与答案解析保持默认字体。
- 每款字体都是按本站用字（约 940 个字：中文界面文案、章节名、知识点标签、420 道题的标题与题干、数字与拉丁字母）用 `pyftsubset` / Google Fonts 子集化后的 `woff2`，17 款合计约 3.2 MB；页面默认只加载当前选中字体，打开下拉框预览时才会加载其余字体。
- 用法：右上角「可爱字体」下拉框选择，选择保存在浏览器 localStorage。
- 所有字体均按 **SIL Open Font License 1.1** 授权，逐款来源与版权信息见 `LICENSES.md`，许可全文见 `OFL-1.1.txt`。
- 未包含的符号（如 ★、☰、✦、→）自动回退系统字体显示。
